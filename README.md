# Hey, I'm Rahul 👋

Full stack JavaScript engineer, shipping web products since 2018. React, Vue, and TypeScript on the front, Python and Node.js behind them, AWS underneath.

**Right now:** building real-time contact center tooling for a Fortune 5 US healthcare client. The latest thing I shipped is a configuration datastore (React + MUI + Monaco Editor on top, Python on Lambda + DynamoDB below) that took config publishing from a 2-minute pipeline run down to milliseconds.

**Before that:** four years deep in US healthcare. A Vue claim settlement portal serving 52K+ users, an Angular to React migration with full UI parity, EDI automation, and a lot of internal platforms.

Things I care about when building:

- Internal tools that people actually open twice
- Fast feedback loops: build times, hot reload, deploy speed
- Debuggability. I once unified frontend and backend Splunk queries so one query traces a whole user journey, and I have never gone back
- Boring, readable code over clever code
